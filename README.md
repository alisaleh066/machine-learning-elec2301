# Machine Learning Data Analysis Project

This repository contains a university machine learning and data analysis project completed as part of ELEC2301.

## Project Overview

The project uses Python and Jupyter Notebook to explore, analyse, model, and evaluate real datasets. The work includes data preprocessing, exploratory analysis, model development, performance evaluation, and a final written report.

## Repository Contents

- `Notebook.ipynb` – Jupyter Notebook containing the analysis, modelling, and evaluation.
- `ELEC2301_Report.pdf` – Final project report.
- `Battery_charge_data.csv` – Dataset used for battery charge analysis.
- `Crops_data.csv` – Dataset used for crop-related data analysis.
